# Проектная работа: "Разработка и реализация аварийного восстановление работоспособности web-сервера и рабочего окружения"

Дорогой коллега! Если ты читаешь эти строки, то это означает, что случилось непоправимое, а меня нет рядом.
Надеюсь, что описанное ниже поможет тебе в кратчайшие сроки восстановить работу наших сервисов...

## Задачи

Цель этой инструкции - выполнение работ по аварийному восстановлению (на "чистых" серверах за короткий промежуток времени) серверов, выполняющих следующие функции:

- вебсервер с балансировкой нагрузки;
- сервера БД (MySQL) (master-slave);
- сервер мониторинга;
- сервер сбора логов.

### Решение

В случае выхода из строя серверов, выполняющих указанные функции, потребуется организовать 3 ВМ:

1. ВМ №1. Вебсервер (стек nginx+apache), с master сервером БД. Рекомендую назвать эту ВМ **db-master**
2. ВМ №2. Slave сервер БД, с сервером мониторинга (стек Prometheus+Grafana). Рекомендую назвать эту ВМ **db-slave**
3. ВМ №3. Сервер сбора логов на базе стека ELK.

Далее поэтапно нужно будет:

- настроить вебсервер с балансировкой нагрузки.
- восстановить БД с бэкапа.
- настроить MySQL репликацию (master-slave).
- на ВМ №2 настроить и скрипт для бэкапа БД со slave сервера.

Убедившись, что основная система работает, перейти к настройке следующих систем:

- система мониторинга;
- система сбора логов.

Все конфиги и скрипты хранятся в репозитории на GitHub.

Копирование репозитория на ВМ:
`git clone git@github.com:DenSarRu/otus_linux_basic_project.git`

Дистрибутивы для установки лежат на сетевом хранилище в разделе "TechOtdel\Distrib".

#### ВМ №1

Если при установке ОС указал некорретное имя сервера, то примени следующие команды:
`sudo hostnamectl set-hostname db-master`
`sudo reboot`

Установка времени:
`sudo timedatectl set-timezone Europe/Moscow`

Теперь в домашнем каталоге пользователя нужно создать директорию **distrib**:
`mkdir ~/distrib`

И в нее с файлового хранилища нужно будет скопировать пакет:

- filebeat_8.17.1_amd64-224190-a5f894.deb

Переходим в директорию репозитория:
`cd ~/otus_linux_basic_project/`

И поочередно запускаем скрипты:
`sudo bash ./01_install-nginx.sh`
`sudo bash ./02_install-apache.sh`

На этом этапе можно проверить работу через браузер, перейдя по адресу сервера.

Теперь настраиваем Базу Данных. Для этого запускаем скрипт:
`sudo bash ./03_install-database_master.sh`

Сразу установим и настроим FileBeats для отправки логов на сервер логирования. Для этого запускаем скрипт:
`sudo bash ./04_install-filebeat.sh`

Он в автоматическом режиме настроит всё необходимое. Проверим это чуть позже.

#### ВМ №2

Если при установке ОС указал некорретное имя сервера, то примени следующие команды:
`sudo hostnamectl set-hostname db-slave`
`sudo reboot`

Установка времени:
`sudo timedatectl set-timezone Europe/Moscow`

Переходим в директорию репозитория:
`cd ~/otus_linux_basic_project/`

И запускаем скрипт:
`sudo bash ./05_install-database_slave.sh`

В случае отсутствия ошибок можно проверить работу скрипта для бэкапа БД со slave сервера.

Это можно сделать выполнив команду:
`sudo run-parts /etc/cron.daily`

После выполнения команды нужно убедится, что в конечном каталоге появились файлы:
`ll /var/db-backup/`

#### ВМ №3

Установим время:
`sudo timedatectl set-timezone Europe/Moscow`

Теперь в домашнем каталоге пользователя нужно создать директорию **distrib**:
`mkdir ~/distrib`

И в нее с файлового хранилища нужно будет скопировать следующие пакеты:

- logstash_8.17.1_amd64-224190-40c12c.deb
- elasticsearch_8.17.1_amd64-224190-db972d.deb
- grafana_12.3.3_21957728731_linux_amd64-224190-b33d09.deb
- kibana_8.17.1_amd64-224190-42bf22.deb

------------
Теперь перейдем к установке и настройке мониторинга.

Переходи в директорию репозитория:
`cd ~/otus_linux_basic_project/`

И запускай скрипт для установки Prometheus на этот сервер и Node Exporter на остальные сервера:
`sudo bash ./06_install monitoring.sh`

Теперь в браузере по ссылке **http://тут_тебе_нужно_указать_IP_ADDRESS_ВМ_№3:9090/classic/targets** можно увидеть состояние сервера Prometheus и опрашиваемых серверов.

------------
Если всё хорошо, то переходи по адресу **http://тут_тебе_нужно_указать_IP_ADDRESS_ВМ_№3:3000** и приступай к настройке Grafana.

Логин/пароль по умолчанию: admin/admin

Нужно подключить источник данных для Grafana: *Connections* -> *Data sources* -> *Add data source* и выбираем **Prometheus**.

В новом окне указываешь имя "Web Server Monitoring".

Ниже в блоке **Connection** в строке *Prometheus server URL* указываешь адрес http://localhost:9090

Доходишь до конца страницы и нажимаешь **Save & test**.

Надеюсь, что ты увидел сообщение "Successfully queried the Prometheus API".

Теперь создадим красивый dashboard.

Для этого переходишь в раздел **Dashboard**, ищещь в правом верхнем углу кнопку **New** и в выпадающем списке выбираешь **Import**.

В строке с надписью *Grafana.com dashboard URL or ID* указываешь **1860** и нажимаешь **Load**.

Если по какой-то причине не удается загрузить этот дашборд, то в файлах (папка statics) этого репозитория есть файл *1860_rev45.json*. Загружаешь его на этой странице и идешь дальше.

На следующей странице нажимаешь *Import* и любуешься картинками.

------------
Можно проверить работу системы мониторинга нагрузив один из серверов командой:
`stress --cpu 2 --vm 2 --vm-bytes 1024M --timeout 3600s`

------------
Теперь переходим к установке и настройке логирования.

Находясь в директории **~/otus_linux_basic_project/** запускаешь скрипт для установки Elasticsearch, Kibana и Logstash (ELK):
`sudo bash ./07_install-logging.sh`

Если всё прошло без ошибок, то по адресу **http://тут_тебе_нужно_указать_IP_ADDRESS_ВМ_№3:5601** можно будет настроить отображение полученных логов.

На стартовой странице переходишь по ссылке **"Explore on my own"**

В меню (три полоски в левом углу) находишь раздел **"Stack Management"**

Идем в **"Data"** -> **Index Management** и там должны быть индексы с именем в формате "weblogs-*<дата>*"

Теперь идешь в раздел **"Analitics"** -> **"Discover"** и выбираешь **"Create data view"**

Указываешь имя (любое), далее в строке **Index pattern** вводишь weblogs-*

Нажимаешь **"Save data view to Kibana"** и попадаешь на страницу с логами.

Теперь построим графики. Идем в меню в раздел **"Analitics"** -> **"Dashboards"**, нажимаем **"Create a dashboard"** и затем **"Create visualization"**

Выбираешь нужные типы графиков и данных. В общем, тут тебе нет никаких ограничений =)
